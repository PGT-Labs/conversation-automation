# Conversation Automation

A Python-based automation tool designed to streamline Facebook Marketplace and Messenger conversations through a web dashboard and a Botpress-powered conversational workflow.

## Overview

This project was developed as a **proof of concept for a real client use case**. It automates parts of the workflow involved in handling Marketplace conversations, combining browser automation, conversation management and chatbot integration.

The application provides a Flask-based dashboard to monitor conversations and manage chatbot activation, while Selenium handles browser interactions with Facebook Messenger and Marketplace.

## Key Features

- **Browser automation:** Automates Messenger interactions using Selenium and Chrome WebDriver.
- **Conversation management:** Retrieves and processes Marketplace conversations and messages.
- **Chatbot integration:** Connects conversations to a Botpress conversational workflow.
- **Web dashboard:** Provides a Flask interface to monitor conversations and control chatbot handling.
- **Automation workflow:** Handles polling, conversation state and message exchanges.

## Tech Stack

- Python
- Flask
- Selenium
- Chrome WebDriver
- Botpress
- HTML / CSS / JavaScript

## Project Status

Built and demonstrated as an MVP for a real client use case. The project was not deployed to production.

The repository is being cleaned up and documented for portfolio purposes. The original implementation reflects the architecture and constraints of the prototype.

## Engineering Context

This project explores the integration of browser automation, web applications and conversational AI into a practical business workflow.

It also illustrates the challenges of automating interactions with third-party web interfaces and coordinating state across multiple components.
